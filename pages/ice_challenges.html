ICE Challenges

What are ICE Challenges?

ICE stands for In-Class Exercises. These are short HTML and CSS challenges meant to be completed in an hour or less. They are meant to give hands-on experience with the concepts covered in class and additional opportunities to practice outside of major projects.

Challenges

  1. Prophet Card – 10/12/26

    For this challenge, we were given a screenshot of a prophet card and asked to recreate it using HTML and CSS.

    While working on this challenge, I had the opportunity to practice using CSS to make a webpage look the way I wanted it to.

  2. Favorite Devotionals and Form – 10/19/26

    For this challenge, we were given a page with some basic styling and asked to add a table and form and style them to match the rest of the page.

    While working on this challenge, I had the opportunity to explore different CSS properties and techniques for styling elements.

  3. Halloween Page CSS – 10/21/26

    For this challenge, we were given the HTML for a Halloween-themed page and asked to style it using CSS.

    This challenge was particularly enjoyable. I found it an interesting challenge to style a page without changing the HTML, as I found that there were a lot of things that I wanted to do that became more difficult without being able to add classes or divs to the HTML.

  4. CSS Positioning Challenges – 10/26/26

    For this challenge, we were given a series of images that we needed to recreate using colored divs and CSS positioning, mainly grid.

    This challenge was an amazing opportunity to practice slightly more complex CSS positioning.

  5. Flags Using CSS Grid – 10/28/26

    For this challenge, we were given a set of flags and asked to recreate them using CSS Grid.

    This challenge was another good opportunity for practicing CSS layout techniques.

  6. Image Gallery – 11/02/26

    For this challenge, we were given an image gallery and asked to make it load more quickly by editing the images provided.

    This challenge was an opportunity to learn about image optimization and the differences between using the .png and .jpg formats.

  7. Sign Up Form – 11/02/26

    For this challenge, we were given a screenshot of a sign-up form and asked to recreate it using HTML and CSS.

    I enjoyed having the final ICE challenge be one that was similar to the first one. It gave me the opportunity to see how far I have come in my HTML and CSS skills and understanding.
